# Rhodes samples

Electric Piano 1 from the FluidR3_GM soundfont (Frank Wen), as rendered to MP3 by
[midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts) (gleitz).
FluidR3_GM is distributed under the MIT license; the MP3 renderings under CC BY 3.0.

One sample every minor third from C3 (MIDI 48) to C7 (MIDI 96). The game pitch-shifts
each note from the nearest sample (at most one semitone), so 17 files cover the range.
